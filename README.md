## 🌟 Visión del Proyecto

Esta landing page representa la propuesta de valor profesional de **Julio Humberto Vera Palacios** (*Licenciado en Administración de Empresas* y *Técnico en Informática Empresarial*). 

Diseñada bajo los más altos estándares de **Creative Development**, combina una estética oscura editorial de lujo (*Swiss Editorial Layout*), animaciones de partículas físicas, rendering 3D en tiempo real con WebGL y navegación interactiva fluida adaptada a cualquier dispositivo.

## 💎 Características Principales

### 1. 🌌 Hero Cinemático & Motor de Partículas 2D
* **Generador de Humo Volumétrico:** Renderizado procedural en HTML5 Canvas con múltiples capas de profundidad, física de fluidos y paralaje reactivo al puntero del mouse y giroscopio.
* **Atmósfera Sonora Inmersiva:** Pista ambiental de baja frecuencia con controlador de audio suave (*fade-in / fade-out*) e interactividad de usuario.
* **Tipografía Dinámica:** Sistema tipográfico suizo escalable con `Instrument Sans` y `Source Serif 4`.

### 2. 🥷 Spotlight 3D Voxel Showcase
* **Avatar 3D Voxel Studio:** Render en alta resolución con estados de interacción (*abrir laptop, escribir código y revelado de agua*).
* **Microinteracciones:** Seguidor de cursor magnético inteligente y efecto de máscara interactiva.

### 3. 🎯 Áreas Destacadas (Servicios Core)
* **01 / Páginas Web, Landing Pages & Apps Android:** Sitios web de alta conversión y aplicaciones móviles nativas personalizadas.
* **02 / Sistemas para PYMES:** Software a medida para control de inventarios, punto de venta (POS), facturación y gestión comercial.
* **03 / Automatización con Excel y VBA:** Macros avanzadas, formularios blindados (UserForms) y dashboards dinámicos para reducir tiempos operativos hasta en un 85%.
* **04 / Soluciones de Ofimática Avanzada:** Plantillas corporativas inteligentes en Word, presentaciones comerciales de alto impacto en PowerPoint y reingeniería de flujos de oficina.

### 4. 🎬 Teatro del Manifiesto (`#enfoque`)
* **Video de Fondo en Bucle (HLS/MP4):** Video atmosférico de alta fidelidad con orbe de iluminación ambiental difuminada.
* **Pilares Estratégicos en Cristal Líquido (*Liquid Glass*):** Tarjetas con elevación física, desenfoque de fondo (*backdrop-filter: blur(28px)*) y bordes de refracción especular.

### 5. 🪐 Consola de Ecosistema 3D Interactiva (`#service-orbit`)
* **Órbita WebGL 3D Real (Three.js):** Núcleo geométrico cristalino central y 5 satélites planetarios en rotación tridimensional constante.
* **Interacción Raycasting:** Detección de puntero sobre nodos 3D, ampliación elástica y sincronización bidireccional con las pestañas de navegación.
* **Panel Head-Up Display (HUD):** Especificaciones técnicas en tiempo real, lista de entregables y botón de cotización directa por WhatsApp con mensaje preconfigurado para cada servicio.

### 6. 📱 100% Responsivo & Accesible
* Diseñado y probado meticulosamente para **teléfonos móviles (iOS y Android)**, tablets, laptops, pantallas de escritorio estándar y monitores ultrawide 4K.
* Cumplimiento de estándares de accesibilidad (*ARIA roles, focus states, skip-links y soporte para `prefers-reduced-motion`*).

## 💻 Instalación y Ejecución Local

### Prerrequisitos
* **Node.js** (versión 16 o superior) o cualquier servidor web estático (*Python, Live Server, etc.*).

### Pasos
1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/JulioHVPalacios/julio-premium-landing.git
   cd julio-premium-landing
   ```

2. **Instalar dependencias de desarrollo:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor local de desarrollo:**
   ```bash
   npm run dev
   ```

4. Abre tu navegador en `http://localhost:8080`.
